# Orbit Digital — Full-Service Growth & Marketing Agency

A high-performance digital marketing agency platform featuring interactive 60 FPS animations, device simulators, in-context visual editing HUD, and a complete enterprise CMS administration console.

---

## 🚀 Features

- **Public Website Showcase**:
  - High-velocity agency presentation across Strategy, Creative, Performance, and Search Intelligence.
  - Interactive Workshops & Innovation showcases with 60 FPS fluid animations.
  - Multi-device responsive simulator (Desktop, Tablet, Mobile).
  - Floating pill navigation bar with expandable Mega Menu and Project Brief Builder drawer.

- **Orbit CMS Management Console**:
  - Accessible via `/admin.html` or the floating **CMS Admin** button.
  - **Dashboard**: Real-time stats, page telemetry, and quick shortcuts.
  - **Content**: Dedicated managers for Pages, Blog Posts, and Media Assets.
  - **Menus**: Header & Footer navigation template configurator.
  - **Sections**: 2-column live layout manager with reordering, code overrides, and section additions.
  - **Settings**: Automated XML Sitemap generator, `robots.txt` editor, 301/302 redirects, and database export/import backups.
  - **Client Briefs**: Inbound client inquiry and proposal generator inbox.
  - **Section Studio**: Zero-refresh visual editor for immediate live content and styling changes.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Styling**: Tailwind CSS v4
- **Bundler & Server**: Vite 8 + Express
- **Icons**: Lucide React
- **Backend & Persistence**: Firebase Firestore + Client Storage Cache
- **Animations**: Motion

## 📦 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
cd YOUR_REPOSITORY
```

### 2. Install dependencies
```bash
npm install
```

### 3. Environment configuration
Copy the example environment file:
```bash
cp .env.example .env
```

### 4. Run the development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📜 Available Scripts

- `npm run dev`: Starts the development server on port 3000.
- `npm run build`: Generates the optimized production build in `dist/`.
- `npm run preview`: Locally previews the production build.
- `npm run lint`: Validates TypeScript syntax and type safety (`tsc --noEmit`).
